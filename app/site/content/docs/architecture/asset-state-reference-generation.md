# 资产状态参考生成

剧本抽取把角色、场景和道具建模为“实体基础 + 可见状态”。状态只在年龄、身份、妆发、服装、空间结构、长期陈设变化、损耗或破损等会改变画面一致性的条件发生变化时创建。

一次性的日夜、晨昏、普通天气、轻微光线变化、姿势、表情或摆放方向默认不创建状态资产。它们由镜头画面提示词修正，继续复用基础参考图。拆分不确定时默认复用基准资产，避免产生只使用一次且无法维持一致性的孤立设定图。

每个实体家族恰有一个基准状态。其余状态记录为派生状态，并保存所依赖的基准资产名称。角色状态共用同一人物基础；场景状态共用同一空间结构和材质体系；道具状态共用同一物件本体、尺寸和关键细节。

造型页会标注每张资产卡被哪些镜头画面使用。删除派生状态时，服务端会先将其镜头角色、场景、道具关联，以及已确认的提取候选改为对应基准资产，再删除该派生状态；同一镜头已有关联基准时会合并重复关联。若基准资产不存在，删除会被拒绝，避免后续画面生成失去参考图。

设定页批量生成按依赖顺序执行：先生成基准图，再生成派生状态。派生任务在实际执行时读取基准图文件并作为参考图提交。若基准图缺失或生成失败，派生任务失败，不会退化为无参考图的独立生成。

镜头拆解使用状态资产的完整名称进行关联，因此镜头帧生成会引用当前剧情所需的角色、场景和道具状态，而不是仅引用实体基础名。

道具只在当前镜头的画面、动作或构图中被明确使用时才建立镜头关联。画面生成会把该道具的基准图作为参考图提交，保持外形、尺寸、材质和关键细节一致；未出现的道具不会因为属于同一项目而被带入画面。旧项目没有保存关联时，前端仅以镜头文本中的精确名称作兼容匹配。

照片、手机屏幕、显示器、相框、海报等承载可见画面内容的道具可记录强关联角色和场景。生成该道具时，系统会把这些实体的造型图一并作为参考图提交，使屏幕或照片中的人物、地点与项目设定一致。普通物件不会建立这种关联，避免把无关人物或地点强加到道具图中。

造型页和分镜页的批量生成均可主动停止。停止会取消正在执行的图片任务，并把尚未开始的项目标记为已停止；已经成功生成的图片会保留。队列状态保存在服务端，用户刷新或离开页面不会使队列停止，返回相应页面后会继续显示进度。画面工作台的单镜头任务轮询与当前选中镜头分离；切换镜头时，镜头列表继续更新原任务状态，切回后会立即用已知状态恢复执行标示，再与服务端记录合并校正。

应用外层持续读取服务端任务列表，因此剧本、设定、分镜、画面之间切换时，正在排队和执行的提示词、图片、视频任务会继续显示在全局状态卡中。状态卡为每项任务提供“停止”操作：普通生成任务请求任务系统取消，同类任务会整组取消；批量图片任务调用批次停止接口，不再提交剩余项目，并取消当前生成项；已经完成的结果继续保留。

本机线程任务收到停止请求后会立即进入已取消状态，执行器即使稍后返回也不会写入结果。后端服务重启时会自动终结上一个进程遗留的本机任务：已请求停止的任务记为已取消，其余中断任务记为失败并允许重新提交，避免界面长期停留在“执行中”或“停止中”。

SQLite 的异步与同步连接均强制开启外键约束，使资产删除时图片槽位和项目关联按数据库定义级联删除。实体删除接口还会显式删除图片槽位，服务启动时会清理旧版本遗留的孤立槽位；因此重做设定后可以安全复用原资产 ID。抽取流程只要有任一实体保存失败就会整步报错，不再把部分写入误报为完成。

设定抽取严格分三阶段执行：先通读全文并分别建立角色身份、物理场景、关键道具清单；再合并同一人的本名/昵称/年龄称呼、同一地点的不同时段和同一道具的不同状态；最后才判断哪些视觉变化值得拆为派生参考图。模型为实体提供 aliases、为状态提供稳定 state_key，程序再次按这两个字段去重，并以最新全文结果覆盖同步同一家族；状态名称换一种说法不会再新增重复卡片，全文中已经消失的自动抽取资产也会被移除。

Bridge pipeline 的剧本抽取、视觉词典和镜头拆解任务会额外保存任务编号；页面卸载不删除任务记录，返回原页面后对应操作仍保持禁用和执行中标示，避免重复提交。Pipeline 每项作业在独立子进程中串行执行，全局状态卡发出取消请求后可终止当前子进程；排队作业会立即取消，运行作业先显示“停止中”，终止完成后移出任务列表。

重新执行会覆盖下一步内容的操作均在提交前显示覆盖提醒。提醒会明确列出被替换的设定描述、视觉词典提示词、造型图、镜头与镜头画面，并说明不会自动同步的更后续产物；用户取消提醒时不会创建任务。首次抽取尚无设定、首次拆镜尚无镜头、首次生成尚无图片时不额外打断流程。

画面工作台批量生成关键帧时，每一项优先读取已保存的首帧、关键帧或尾帧提示词；没有已保存提示词时，先调用默认文本模型生成并保存提示词，再提交图片任务。文本模型任务失败时，服务端才使用景别、镜头标题、镜头描述和剧本摘录构造并保存基础提示词，随后由统一图片提交链补入角色、场景、道具和连续性约束。

画面工作台支持批量导出当前项目已有的关键帧。导出 ZIP 只读取已生成图片，不会触发生成；文件按“第几集_第几镜_镜头标题”命名，便于交付与剪辑整理。
